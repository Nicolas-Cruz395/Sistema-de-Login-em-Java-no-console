🔐 Sistema de Login em Java (Console);

Um sistema simples de autenticação desenvolvido em Java, executado via terminal.  

O projeto permite cadastro de usuário, login com validação e controle de tentativas.

-------------------------

📌 Sobre o projeto;

Este projeto foi criado com o objetivo de praticar conceitos fundamentais da programação em Java, como entrada de dados, estruturas de controle e lógica de autenticação.

O sistema simula um ambiente básico de login, onde o usuário pode se cadastrar e posteriormente acessar o sistema com suas credenciais.

-------------------------

⚙️ Funcionalidades;

- ✅ Cadastro de usuário (login e senha)

- ✅ Login com validação de credenciais

- ✅ Limite de 3 tentativas de acesso

- ✅ Mensagens de erro informativas

- ✅ Menu interativo no console

- ✅ Encerramento do sistema

-------------------------

🧠 Como o sistema funciona;

1. O usuário informa seu nome ao iniciar o programa

2. Um menu é exibido com as opções:

[1] - Cadastro

[2] - Login

[3] - Sair

3. O usuário precisa se cadastrar antes de fazer login.

4. O sistema compara os dados digitados com os cadastrados.

5. O usuário possui até 3 tentativas de login.

6. Após exceder o limite, o programa é encerrado.

-------------------------

💻 Como executar o projeto

📋 Pré-requisitos

- Java JDK instalado (versão 8 ou superior)

▶️ Passos para execução

Abra o terminal na pasta do projeto e execute:

```bash

javac Login.java
